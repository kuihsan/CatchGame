# 🍎 Catch Game (WebGL)

A simple and fun **apple-catching browser game** built with **Unity WebGL**, designed for both **mobile and PC users**.  
Players enter their name, catch falling apples using a basket, and their **score is recorded automatically** to Google Sheets.

🎮 **Play the game here:**  
👉 https://kuihsan.github.io/CatchGame/

📊 **Live score data (Google Sheets):**  
👉 https://docs.google.com/spreadsheets/d/1L8tV40cYq415tanHV1EzM25xQVOpZvplVLfh34gztH8/edit?usp=sharing

---

## 🕹️ Gameplay Overview

- Enter your name at the start of the game
- Apples fall from the top of the screen
- Move the basket to catch the apples
- Gain points for each apple caught
- Miss **3 apples** and the game ends
- Score and player name are submitted automatically

---

## ✨ Features

- 🌐 **Unity WebGL** (Playable directly in browser)
- 📱 **Mobile-friendly** (Touch input supported)
- 🖱️ **PC support** (Mouse + keyboard)
- ⌨️ **HTML overlay input** (Fixes mobile & WebGL keyboard issues)
- 🔁 **Auto restart** after game over
- 📊 **Google Forms → Google Sheets integration**
- 🎯 Simple, casual, customer-friendly gameplay

---

## 🧑‍💻 Controls

### Mobile
- Drag / touch to move the basket

### PC / Laptop
- Move mouse to control the basket
- Type name using keyboard
- Press **Enter** or click **Start** to begin

---

## 🛠️ Tech Stack

- **Unity** (Game engine)
- **C#** (Gameplay logic)
- **WebGL** (Browser deployment)
- **HTML / JavaScript** (Name input overlay & Unity bridge)
- **Google Forms & Google Sheets** (Score storage)

---

## 📂 Data Collection Flow

1. Player enters name
2. Game starts and score is tracked
3. On game over:
   - Player name
   - Final score  
   are sent via **Google Form POST**
4. Data is stored automatically in **Google Sheets**
